# Simple Shopping Mall UI

간단한 쇼핑몰 UI 구현 프로젝트입니다.

## 기능

- ✅ 상품 목록 표시 (8개의 샘플 상품)
- ✅ 장바구니 기능
  - 상품 추가/삭제
  - 수량 조절
  - 장바구니 비우기
- ✅ 주문하기 기능
- ✅ 반응형 디자인 (모바일/태블릿/데스크톱)
- ✅ 로컬 스토리지를 활용한 장바구니 데이터 저장
- ✅ 알림 메시지

## 사용 방법

1. 브라우저에서 `index.html` 파일을 엽니다.
2. 상품 목록에서 원하는 상품의 "장바구니에 추가" 버튼을 클릭합니다.
3. 우측 상단의 장바구니 버튼을 클릭하여 장바구니를 확인합니다.
4. 장바구니에서 수량 조절 및 삭제가 가능합니다.
5. "주문하기" 버튼을 클릭하여 주문을 완료합니다.

## 기술 스택

- HTML5
- CSS3 (반응형 디자인)
- Vanilla JavaScript (ES6+)
- Local Storage API
